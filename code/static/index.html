How Relay works

Every incoming message is classified by a Groq-hosted LLM into notify, digest, or mute, personalized to each user's engagement history.

A separate rule-based safety layer runs in parallel and can override the AI's decision to mute scams or risk messages, regardless of personalization.

The sidebar shows real classification decisions from the pre-loaded dataset. Use the composer at the bottom to test your own messages live.
